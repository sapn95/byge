byge

A self-hosted kanban board in one static Go binary. Byge is Bernese German for a stack, and byge is the verb for stacking it: a column is a stack of cards, so the name is also the instruction.

A fork

It began as a fork of NicolasHaas/golang-kanban at its v1.0.1, which was one Postgres table of cards under three fixed columns. The boards, columns, labels, comments, archive, search, response times, identity and JSON API came after that.
